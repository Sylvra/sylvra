## Work with me

| Engagement | Best for | Shape |
|---|---|---|
| **Project-based** | A site, an app, a defined scope | Fixed scope, fixed timeline, staged delivery |
| **Retainer** | Ongoing evolution and maintenance | Monthly, recurring, priority access |
| **Consulting** | Architecture, motion systems, infrastructure review | Audit, recommendations, handover document |

**I take on**

- Marketing sites and web experiences with real motion design
- Front-end architecture, design systems, performance work
- Desktop and backend applications
- Infrastructure, virtualization, automation and hardening

**How I work**

Scope agreed in writing before anything is built. One section at a time,
reviewed as it goes. Every deliverable documented well enough that you can
maintain it without me.
