## What I do

**Creative front-end**
Animated, scroll-driven interfaces. Motion as structure, not decoration.
React, Next.js, TypeScript, GSAP + ScrollTrigger, Framer Motion, Tailwind, Three.js.

**Application development**
Desktop and backend work, tooling, automation.
C++, C#/.NET, Java, Node.js, Python.

**Systems & operations**
Windows and Linux administration, virtualization, scripting and automation.
PowerShell, Bash, VMware, Docker, Git, CI pipelines.

**Security**
Hardening, monitoring, and defensive practice applied to the infrastructure I run.
